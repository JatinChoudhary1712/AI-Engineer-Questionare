**Har answer ka format:**

1. **One-line answer first:** pehli line mein seedha definition ya core idea.
2. **Keywords bold:** sirf important terms bold karo (jaise **data leakage**, **precision**). Poora sentence ya paragraph bold mat karo.
3. **Short bullets (3 se 5):** har point alag bullet aur nayi line mein, ek point mein ek hi idea. Har point mein key term bold karo, phir uski explanation do.
4. **Formula/example alag line mein:** jahan relevant ho, formula (jaise `Precision = TP / (TP + FP)`) aur ek real example (spam filter, cancer detection) do.
5. **Remember one-liner:** answer ke end mein ek memory trick ya takeaway do.

**Extra rules:**
- Language simple English, technically accurate aur interview-friendly.
- Sequential steps ke liye numbered list, comparisons ke liye table use karo.
- Related concepts ka connection clearly dikhao, jaise high bias → underfitting, high variance → overfitting.
- Sirf diye gaye sections/questions update karo, baaki content preserve karo.
- Questions ka wording change mat karo, aur duplicate questions mat banao.
- Changes ke baad JavaScript syntax check karo (quotes, commas, brackets) taaki page break na ho.
