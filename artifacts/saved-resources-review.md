## Persistence

Both entries are bundled into `recall-app.js` and imported into `recall.notebooks.v1` on the next app load. `recall.bundled-resources.v1` records each import so refreshes do not duplicate entries or restore an item after the user deletes it. ## Resource table interface

The Saved Resources card title, item links, sidebar entry, and View all action open the dedicated `resources.html` page. It presents a full-width table with exactly two columns: Main info and Link. Shirin's post expands into its 16 categorized practice prompts, each paired with the resource URL supplied in the post. Search filters the table. Links open their original destinations in a new tab.

The table view has Add resource, Edit item, and My notes controls. Personal notes open below the table and save to the same existing item. The full collection uses Manage items when several resources are present. The editor remains available at `index.html?page=resources&edit=1`; adding an item uses `index.html?page=resources&new=1`. Existing notes, statuses, resource data, deletions, and import markers are retained.
